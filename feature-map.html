🧭 FUNCTION GUIDE

何をしたいですか？

教材を読む、AIで分析した文章を取り込む、動詞を分解する。目的から選べます。既存の画面はそのまま使えます。

📖教材で学ぶ

A1〜C2を選び、状況・単語・文・音声の順に学びます。

Learn → 🤖AIで分析した文章を取り込む

分析プロンプトをコピーし、AIの解析結果を教材として読み込みます。

AI Material → ✍️自分の文章を調べる

ロシア語を入力し、単語や構造を選んで深掘りします。

My Material → 🧠動詞を詳しく分析する

対応済みの動詞について体・語形・構造・語族をまとめて見ます。

Verb Explorer → 🔄完了体と不完了体を比べる

同じ出来事をどう捉えるか、二つの体の違いを探索します。

Aspect Lab → 🧬形態素の研究室を探す

接頭辞・接尾辞・語族などの専門ラボへ移動します。

Morphology Hub → ↗️接頭辞を比較する

動詞の前に付く要素が持つ意味の傾向を比較します。

Prefix Lab → 🧩接尾辞・語幹を調べる

動詞形成や語幹交替の例を比較します。

Suffix Lab → 🌳語族をたどる

共通する語根から関連語のつながりを見ます。

Word Family Lab → 📚教材のレベルと進捗を見る

A1〜C2の教材登録状況を確認します。

Curriculum → 🧪形態素データを検査する

登録済み分析データの内部整合性を確認します。

Morphology Check → 🕰️以前の教材を開く

移行前の学習画面・教材を残しています。
